# AI Hub

[English](README.md)

一个适合新手的、类似微信的桌面程序：**把多个 AI 拉进一个群里开会**。
Claude、Gemini、Grok、豆包、ChatGPT、DeepSeek……坐在同一个群里一起讨论你的问题。
只用 **Python 标准库**（tkinter + urllib + json），不需要 `pip install`。

## 功能（v0.3.0）

- 聊天软件式界面：左侧是群聊列表和 AI 成员（彩色头像）；右侧是聊天气泡（你在右边，AI 在左边并显示名字和时间）；底部输入框（Enter 发送，Shift+Enter 换行）。
- **建群 / 开会**：群名、选择成员、可选会议主题、可选**主持人**。群和聊天记录以 JSON 保存。
- **会议模式**
  - **轮流发言**：每位成员依次发言，能看到完整记录，可设 1–3 轮。
  - **@某个AI**：输入 `@Grok ……`（或选择“@指定成员”），只有被点名的成员回复。
  - **自由讨论**：成员依次发言并互相回应；没有新观点可回复 `[跳过]`，全部跳过则提前结束。
  - **主持人**：每轮最后由主持人控场；点 **📝 会议总结**，由主持人总结结论、分歧和行动项。
  - **📣 召集开会**：点名，每位成员回复“准备好了”。
  - **⏹ 停止**：中止正在进行的会议（当前请求结束后停止）。
- 每个 AI 都会收到系统提示：它在名为 X 的群会议中、成员有 Y，要简洁、点名回应、不重复别人。可给每个成员设置人设。
- 服务商：DeepSeek、OpenAI、**Anthropic Claude**（原生 `/v1/messages`）、**Google Gemini**（OpenAI 兼容接口）、**xAI Grok**、**豆包/火山方舟**（模型填推理接入点 ID `ep-…`）、**智谱 GLM**、Moonshot (Kimi)、通义千问，以及任意 OpenAI 兼容接口。
- 成员可自定义（名字、服务商、模型、人设、颜色）；同一服务商可以出现多次，扮演不同角色。
- 请求在后台线程运行，界面不卡；某个成员出错会显示红色气泡，其他成员继续。

## 运行

需要 Python 3.10+（python.org 的 Windows 安装包自带 tkinter）。

```bash
python ai_hub.py
```

1. **⚙ 设置 → 服务商 API Key**：填入你有的 Key（没有 Key 的成员显示为灰色）。
2. **⚙ 设置 → AI 成员**：添加/编辑成员。
3. **＋ 新建群聊**：起群名、选成员、主题和主持人。
4. 输入消息发送；在输入框上方选择模式和轮数。

## Key 和聊天记录存在哪里？

**默认便携模式**：保存在 `ai_hub.py` 旁边的 `.ai_hub` 文件夹（`.ai_hub/config.json`、`.ai_hub/groups/*.json`），不会写到 C 盘用户目录。
设置环境变量 `AI_HUB_CONFIG_DIR` 可改用其他文件夹。Key 是明文保存的；`.ai_hub/` 已在 `.gitignore` 中——不要提交或分享。
从 0.2.0 及以前升级：把 `~/.ai_hub/config.json` 移到新的 `.ai_hub` 文件夹即可。
